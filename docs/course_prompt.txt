ROS 2 Humble is already installed. You may use sudo; it does not ask for a password. Before each step, explain in one plain-English sentence what the step does. Commands time out after 60 seconds, so run long installs and builds in the background and check on them.

Follow this tested recipe:
1. sudo apt update; sudo apt install -y git python3-venv python3-pip python3-colcon-common-extensions python3-rosdep ros-humble-xacro; sudo usermod -aG dialout $USER; sudo apt remove -y brltty (on Ubuntu 22.04 it grabs the USB-serial chip some Dobots use, and the robot's port disappears)
2. git clone the repo into ~/dobot_ws/dobot-magician-ros2-mujoco and work in that folder.
3. source /opt/ros/humble/setup.bash; if rosdep was never initialised run sudo rosdep init; run rosdep update; then rosdep install --from-paths src --ignore-src -r -y
4. python3 -m venv --system-site-packages .venv_ros_mujoco; activate it; python -m pip install -U pip; python -m pip install mujoco==3.13.0 pybullet==3.2.7 transforms3d==0.4.1 pyserial==3.5; python -m pip install --no-deps -e mujoco_sim (--no-deps on purpose: it keeps the system numpy that OpenCV needs)
5. With the venv active: python -m colcon build --symlink-install (all packages). Success = no "failed" in the summary.
6. Every new shell needs: export ROS_LOG_DIR=$HOME/dobot_ws/ros_log; source ~/dobot_ws/dobot-magician-ros2-mujoco/setup_env.bash
7. Simulation check: start ros2 launch mani_mujoco dobot_mujoco.launch.py viewer:=true publish_camera:=false in the background, wait until it is up, then run
   ros2 service call /mani/sim/reset_scene mani_interfaces/srv/ResetScene "{randomize: true, seed: 42}"
   ros2 action send_goal /mani/pick_object mani_interfaces/action/PickObject "{object_uuid: pick-object-0, group_name: arm, end_effector_name: gripper, approach_distance_m: 0.08, lift_distance_m: 0.09, velocity_scale: 0.5, acceleration_scale: 0.5}"
   Report whether the pick succeeded, then stop the simulation.
Keep it minimal: do not add or change files in the repository, and stop once the pick result is known.
